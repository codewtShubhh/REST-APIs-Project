# REST APIs Project

A simple REST API project developed as part of my DecodeLab internship.

## Technologies Used

- Python
- Flask
- REST API
- JSON

## Features

- Get all users
- Get a user by ID
- Add a new user
- Update user details
- Delete a user
- JSON-based API responses

## How to Run

1. Clone the repository.
2. Create and activate a virtual environment.
3. Install Flask.
4. Run the application.

```bash
python app.py
